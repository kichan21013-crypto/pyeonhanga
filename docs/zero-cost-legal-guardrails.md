# 나가치 0원 검증 운영 및 법적 경계 (2026-11-24)

> 본 문서는 현재 공개 법령과 무료 플랜 안내를 기준으로 한 제품 개발 가드레일입니다. 법률 자문이나 사업 인허가 확인을 대체하지 않으며, 유료/오프라인 운영 전에는 관할 행정청과 구체적 서비스 계약을 기준으로 검토해야 합니다.

## 1. 무료 운영을 유지하는 기능

- **Cloudflare Workers Static Assets**에 생성된 정적 HTML/CSS/JS와 JSON만 올립니다. 유료 Worker 함수·유료 호스팅·도메인·결제 API·상용 지도·SMS·OAuth·인증서비스·유료 AI API를 추가하지 않습니다.
- GitHub 공개 저장소의 현재 CI/빌드 워크플로와 Node 내장 도구를 유지합니다. 자동 유료플랜 전환 기능을 구현하지 않습니다.
- **Supabase Free 연결은 선택**이며, 실제 연결됐다고 확인된 경우에만 명시적 동의를 받은 익명 수요 기록을 저장합니다. 앱은 분석 미연결 시 '미저장'을 표시합니다.
- Cloudflare 공식 문서: Static Assets 요청은 무료이고 별도의 에셋 보관료가 없습니다. 단 유료 Worker 실행·다른 서비스 사용량은 별개입니다. https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/
- Supabase 무료 프로젝트는 7일간 활동량이 부족하면 일시중지될 수 있으며, 결제하지 않아도 항상 가용하다는 보장은 없습니다. https://supabase.com/docs/guides/platform/free-project-pausing
- 무료 DB는 **신뢰할 수 있는 장기 백업 수단이 아닙니다.** 운영자가 관리자 화면에서 보관기간/저장 여부를 확인하고, 수집이 시작되면 안전한 방법으로 정기적으로 데이터를 추출·백업하는 절차를 마련해야 합니다. 이 PR에서 외부 백업 인프라나 주기 실행 요금은 추가하지 않습니다.

## 3. 주요 법적 검토 포인트

**관광진흥법 제3조·제4조:** 여행업에는 운송·숙박 시설 이용 알선, 여행 안내, 여행 편의 제공 등이 포함될 수 있으며 여행업은 등록 대상입니다. 식비/교통비를 개인이 현장 결제한다는 사실만으로 모든 서비스가 여행업이 아니게 되는 것은 아닙니다. 사전에 관할 시·군·구 관광 담당부서와 사업 유형·계약 주체·서비스비 구성·여행 안내 범위를 서면으로 확인해야 합니다. https://www.law.go.kr/LSW/lsInfoP.do?efYd=20260512&lsiSeq=279659

**여객자동차 운수사업법 제81조:** 자가용 자동차 유상운송 및 이를 알선하는 행위는 원칙적으로 금지되며 일부 법정 예외가 있습니다. 운행 경비를 받는 방식도 유상 범위에 해당할 수 있어, 앱에 '유상 카풀/운전자 연결/차량비 공동정산' 기능을 넣지 않습니다. 허가된 운송수단을 각자가 직접 선택하게 하는 안내만 검토합니다. https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1028670527

**개인정보 보호법 제3조·제15조·제23조:** 목적에 필요한 최소 정보만 적법하게 수집하고, 민감정보는 특히 엄격하게 다룹니다. 현재 설문은 연령대, 선호 인원·동행 구성, 활동 목적, 서비스비 의향만 다룹니다. 전화번호·실명·건강상태·성생활·혼인상태를 요구하지 않으며, 결혼 여부로 사람을 구분하거나 다른 사람에게 공개하지 않습니다. https://www.law.go.kr/LSW/lsInfoP.do?efYd=20260911&lsiSeq=283839

## 4. 유료 전환 전 필수 의사결정

1. 등록 필요성: 장소·코스 기획과 동행 구성의 경계가 여행업/여행 안내에 해당하는지 관할 관청에 확인.
2. 실제 교통: 차량 운송은 허가 받은 사업자와 이용자가 적법하게 직접 거래할 수 있는 구조로 별도 검토.
3. 오프라인 안전: 본인 확인의 적정 방식, 미참석·환불·취소, 사고 및 응급대응, 모임 운영자 책임, 보험 등 준비.
4. 개인정보: 정식 모집을 위해 연락처·확인 서류 등 수집이 정말 필요한 단계에서 별도 이용약관·처리방침·보유기간·권한관리를 설계.
5. 데이터: '관심 → 장소 선택 → 설문 완료 → 지불 의향'을 **실제 매출/모임 참여와 구분**해 측정. 오픈 후 실제 의향이 입증되기 전에는 유료 개발·광고·상용 API를 도입하지 않음.
