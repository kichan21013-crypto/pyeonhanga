# 나가치 운영실 v39 — 관심에서 실제 모임 준비까지

## 처음 접속
[운영실](https://pyeonhanga.kichan21013.workers.dev/admin.html)에 접속합니다. 기존 Supabase 프로젝트와 관리자 계정이 이미 설정됐다면 그대로 로그인합니다. 미설정이면 [v23 연결 안내](v23-owner-db-setup.md) 및 [v26 통합 설치 안내](v26-business-dashboard.md)를 확인합니다. 운영 DB 백업 및 스키마 호환성 확인 후 필요한 SQL만 실행하세요. 비밀번호/서비스 역할 키는 공유하거나 저장소에 넣지 않습니다. v39는 기존 RPC를 사용하므로 추가 SQL은 없습니다.

## 운영 순서
1. 운영 현황의 사업 운영 지표에서 오늘/7일/30일을 선택합니다. 실제 집계된 관심 장소를 코스 기획 버튼으로 불러옵니다. 집계는 동의 설문 기기 기준으로 실제 사람 수가 아닙니다. 장소 목록에 존재하는 지원 지역만 표시합니다.
2. 코스 이름·활동·지역·첫 장소가 입력됩니다. 소개와 나머지 장소를 직접 확인해 저장합니다. 기본 비공개이며 직접 공개를 선택하기 전에는 게시되지 않습니다.
3. 공개 코스에서 모임 초안 만들기를 선택하면 코스와 소개가 연결됩니다. 일정·정원·집결지와 운영 안전을 검토하고 저장합니다. 자동 공개·모집은 없습니다.
4. 운영 현황에서 조회 기간 TOP 10 모임 중 승인 대기가 있는 모임 최대 5개를 빠르게 확인합니다. 전체 신청은 동행 모임 메뉴에서 확인합니다. 신청 관리에서 직접 승인·대기·취소합니다. 정확한 집결지는 승인된 신청자에게만 안내합니다.
5. 수익 계획은 서비스비 가정만 계산합니다. 결제는 아직 제공하지 않습니다.

## 운영 점검
실제 DB 권한과 로그인, 다른 테스트 브라우저의 관심·신청 저장, 공개/비공개 전환, 승인·취소, 로그아웃을 검증해야 합니다. 배포 후 홈에는 v39가 표시됩니다. 본격 유료 운영 전에 사업자 신고·여행업 해당 여부·환불 및 안전절차를 검토하세요. 화면의 AI 제작 사진 표기는 배너 밖으로 옮겼습니다.
