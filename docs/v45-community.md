# v45 이야기 및 계정형 동행

비로그인 탐색·관심·게시글 읽기. 모임별 일정 소식은 계정 수신 동의 후 앱 내 확인, 참가 신청은 카카오 로그인 후 별도 동의. 로그인에서 원래 화면으로 복귀하며 신청을 자동 제출하지 않습니다. 관리자 일반 로그인 시 운영실 이동 유지.

공개 텍스트 게시글, 본인 삭제·신고·관리자 숨김/복원 기능. 사진, 댓글, 좋아요, 푸시, 자동 알림 발송, 회원 탈퇴는 미구현. 공개 피드는 최근 60개. 실제 게시글 없이 시작하며 관리자만 신고 집계를 확인합니다.

SQL: supabase/v45-member-actions-community.sql. 이전 익명 신규 참가 신청 RPC 권한 폐지, 기존 신청 0건 확인 후 적용. 계정별 중복 차단 및 기존 운영자 승인·정원 로직 유지. 실제 회원 모집 전 개인정보 처리방침·탈퇴·게시판 운영규칙 및 신고 대응 검증 필수.

## v46 UI 개편

자유게시판 목록에는 분류·제목·별명·날짜만 노출합니다. 제목을 누르면 본문과 신고/본인 삭제/관리자 숨김 메뉴가 나타납니다. 글쓰기는 별도 화면이며 기존 인증 및 RPC를 유지합니다. 연결 실패와 빈 게시판을 구분하고 하단 메뉴 이름을 게시판으로 바꿉니다. 초록은 동행 관심, 파랑은 알림, 테라코타는 참가 및 글쓰기, 중립색은 탐색과 필터, 붉은 테두리는 삭제/신고/취소에 사용합니다. 기존 DB 변경과 유료 서비스 도입은 없습니다.

## v47 무료 커뮤니티 시범 운영
- 댓글과 공감은 카카오 계정으로 작성하며 공개 읽기는 로그인 불필요. 댓글 신고/본인 삭제/관리자 숨김 및 복원, 계정별 공감 중복 방지. 댓글은 하루 20건, 공감은 하루 100건 신규 등록 제한(삭제 시 해당 기록 사라짐).
- 사진은 글당 1장, JPEG 최대 120,000바이트, 총 300장(원본 합계 최대 36MB). 브라우저에서 최대 1000px로 재인코딩하여 원본 메타데이터를 전달하지 않음. 서버는 JPEG 시그니처와 길이를 확인하며 픽셀/유해 이미지 분석은 하지 않음. 사진은 상세에서만 읽고 글 삭제 시 함께 삭제. HEIC 원본은 현재 미지원. 무료 검증 규모에서는 별도 파일 저장소 대신 제한된 private DB 테이블 사용; 확장 전 Storage 전환 검토.
- DB 적용 순서: supabase/v47-community-engagement.sql, supabase/v47-community-photo.sql. 기존 v45 게시글/계정/모임 유지. DB 백업 및 무료 한도 확인 후 적용. 공개 모집 전 회원 탈퇴, 개인정보 처리방침, 신고 운영 절차 필요.
- 사업 원칙: 커뮤니티 무료, 50+ 중심 취향 동행 수요 검증, 이후 코스 제안·멤버 구성·일정 조율 서비스비 모델 검증. 결제·유료 API·차량 연결 없음. 공감 수는 게시글 반응이며 동행 관심/참가 수로 사용하지 않음.
