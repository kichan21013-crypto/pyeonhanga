기존 v22~v24 기능은 유지합니다. 실제 사람의 신원/참석 확인, 유료 결제, 연락처 수집은 제공하지 않습니다.

## 운영자 사용
- 동행 모임에서 공개 단계, 미래 일정(90일 이내), 안전한 공개 집결 장소, 정원을 설정합니다.
- 모임 목록의 참가 신청 관리 → 무료 시범 모집 시작. 기존 공개 모임은 자동 모집하지 않습니다.
- 신청 번호를 확인하여 승인/대기/취소를 각각 선택합니다. 승인 정원은 2~8명 범위의 기존 설정을 사용합니다. 같은 모임에서 신청·승인·정원 수정은 서버가 부모 모임 행을 잠가 직렬화합니다.
- 접수 마감은 새 신청만 막습니다. 기존 승인·대기 신청은 남습니다. 모임 자체를 취소하려면 접수 마감 후 신청을 각각 취소해야 합니다.
- 신청 대기·승인·대기자 기록이 있는 동안 일정, 장소, 제목, 소개, 연결 코스 변경 등은 제한됩니다. 취소 후 다시 기획하세요. 연결된 코스 자체를 수정하여 일정 내용을 바꾸는 것도 피하세요.
- 정확한 집결지는 공개 소개나 활동별 공지에 넣지 않습니다. 승인된 기기의 내 신청 화면에서만 제공하는 것을 원칙으로 합니다.
- 운영자는 참가자의 실제 신원, 성인 여부, 출석 여부를 확인할 수 없습니다. 성인 자기확인·동의만으로 운영합니다. 앱 내 상태 확인 외 자동 통지는 없습니다. 사전 안전 수칙, 사고·취소 대응, 현장 진행 및 법적 검토 없이 실제 모임을 시작하지 마세요.

## 고객 사용
무료 시범 모집 버튼 → 성인 자기확인 및 저장 동의 → 내 동행 신청에서 승인 대기/승인/대기자/운영자 취소 상태 확인. 승인된 신청은 미래 집결지를 표시합니다. 동일 브라우저에서 한 모임에 한 건만 등록됩니다. 신청 취소·삭제 버튼은 해당 서버 기록을 제거합니다. 기기 변경/브라우저 삭제 시 기록 접근을 잃을 수 있습니다. 신청은 실제 출석 또는 신원 보증이 아닙니다.

## 검증
- 초기 모집 비활성, 공개·일정·집결지 조건 누락 시 모집 불가.
- 익명/일반 Auth 사용자 관리자 RPC 접근 거절.
- 서로 다른 테스트 브라우저로 신청, 중복 신청 한 건 유지, 정원 초과 승인 거절, 대기→승인, 승인 취소 후 정원 해제.
- 승인 전/취소 후 집결지 비노출, 본인 기기의 신청만 조회, 마감 후 신규 신청 불가, 기존 신청 취소 가능.
- 참가 신청 후 일정·집결지 변경 및 정원 축소 제한.
- 서버 실패 시 성공으로 표시하지 않는지, 새로고침/로그아웃 후 정보 노출 여부 확인.
- 30일 경과 신청 기록은 SQL 파일 마지막의 정리 쿼리를 운영자가 정기 실행. 물리 삭제 자동화는 별도입니다.
- 기기 토큰을 재생성하면 중복 신청이 가능할 수 있으므로 본격 운영 전 계정/남용 방지/신원 및 안전 절차 검토. 모임별 최대 200개 신청 레코드 제한은 남용을 완전히 방지하지 않습니다.
