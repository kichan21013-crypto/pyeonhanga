# 나가치 v48 — 지인 사용성 테스트 준비

## 원칙
- 50대 이상 우선 수요 검증. 취향에 맞는 사람들이 함께할 모임을 나가치 운영자가 기획하는 서비스이며 소개팅/중개 서비스가 아니다.
- 기존 무료 인프라, 승인된 배너 사진 및 관광공사 실제 장소, 로그인, 관심 집계, 모임 공지, 게시판 기능을 유지한다.
- 신규 유료 API, 유료 호스팅, 결제, 개인정보 수집 필드, DB 변경 없음.
- 관심 표현은 참가 신청이 아니다. 실제 관심 집계가 없을 때 추천 후보라고 표시하며 가짜 인기/인원 수를 보여주지 않는다.

## 핵심 디자인
- 브랜드의 초록은 로고와 기존 정체성에서 유지. 이벤트 탐색과 안내는 네이비·흰색, 관심 등록은 깊은 코랄, 실제 선택은 4가지 활동 색과 체크 표시를 사용한다.
- 활동·장소·카드 버튼 텍스트 확대, 주요 클릭 영역 최소 44px 목표.
- 홈에서 서비스 목적 한 문장으로 설명하고 활동 카테고리 바로 아래에서 장소명/활동 검색 접근. 검색 결과는 검색 영역 바로 아래 표시.
- 인기 동행 카드의 관심 버튼은 실제 효과가 드러나는 '관심 남기기'. 추천 후보 상태에는 참가 신청이 아님을 안내한다.
- 사진 자산과 기존 v47 기능은 변경하지 않는다.

## 1차 지인 테스트 (권장 5~8명, 개인별 5~10분)
설명하지 말고 먼저 스스로 화면을 탐색하도록 한다. 테스트 참가자에게 시험 운영임을 고지하고, 실제 관심이 없다면 최종 관심 등록/신청을 하지 않는다. 운영 데이터에 임의로 가짜 응답을 입력하지 않는다. 이름, 전화번호 등의 개인정보는 평가 기록에 적지 않는다.

| 행동 과제 | 관찰 |
|---|---|
| 홈을 5초 보고 무엇을 하는 앱인지 설명하기 | 모임을 운영자가 기획한다는 점 이해 여부 |
| 본인이 가고 싶은 지역의 맛집/나들이 찾기 | 첫 클릭 위치, 30초 내 탐색 성공 |
| 원하는 장소명 직접 검색하기 | 검색 시작 위치, 결과/없음 안내의 이해 |
| 관심 남기기 화면 열고 다음 단계로 이동하기 | 진짜 참여 신청과 관심의 차이, 글자 크기 |
| 장소 저장 및 다시 확인하기 | 하단 메뉴 이름의 직관성 |
| 게시판에서 글 찾아보기 | 목록·상세 이동, 사진·댓글·공감 발견 여부 |
| 내 계정 및 동행 소식 찾기 | 위치와 아이콘 의미 이해 여부 |

### 테스트 후 질문
1. 첫 화면을 보고 어떤 서비스라고 생각했나요?
2. 모임을 찾거나 관심을 표현하기 쉬웠나요? (1~5점)
3. 글씨 또는 버튼 중 작거나 의미를 알기 어려운 것이 있었나요?
4. 색상과 카드 디자인이 보기 좋고 믿음이 갔나요? (1~5점)
5. 실제 이런 모임을 나가치가 기획해 준다면 관심이 있나요? 어떤 활동/지역인가요?
6. 가장 먼저 고쳐야 한다고 느낀 한 가지는 무엇인가요?

테스트는 실제 상품 판매·모임 참가 확정이 아닌 사용성 및 수요 검증이다. 같은 사용자에게 기능 안내 후 다시 해 보게 하면 학습 효과를 구분해 기록한다. iOS Safari 및 Android Chrome 실제 기기에서 터치, 안전 여백, 뒤로가기, 느린 네트워크를 별도 확인한다.
