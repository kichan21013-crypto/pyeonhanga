# v30 승인 시안 홈 적용

- 사용자가 승인한 홈 시안에서 40대 남녀 카페 장면만 잘라 256×165 WebP(4,414 bytes)로 등록. 실제 참가자 사진이 아니며 연출 이미지로 표시. 문구와 CTA는 실제 HTML 요소.
- 카테고리 이미지 4개 및 기존 선택 흐름 유지. 상단 동행 소식 버튼은 기존 수신 공지, 사람 아이콘은 동행 안내로 연결.
- 인기 동행 영역: 2개 카드가 화면에 표시되는 가로 레일, 실제 순위 배지, 관심 건수, 장소 저장 하트, 실제 관심 설문 버튼. 전체보기는 현재 후보 목록을 펼침.
- 실제 순위가 없는 경우 나가치 추천 동행 및 추천 배지로 대체. 가짜 관심 인원이나 급상승 표시 금지. 장소 분류는 실제 데이터 사용.
- 버튼 흰색 글자, 명확한 섹션 구분, v30 캐시 버전. 새 DB/비용 없음. 운영 데이터 저장 규칙 오류는 별도 Supabase 적용 확인 필요.
- 전체 빌드/실기기 검증 및 배포 확인은 별도.
