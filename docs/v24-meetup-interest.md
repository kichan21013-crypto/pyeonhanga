# 나가치 v24 모임별 관심 등록

## 새 기능
- 일반 홈에서 운영자가 공개한 모임에 별도 동의 후 관심 등록 또는 취소.
- 동일 브라우저 비밀값과 모임 조합은 한 건으로 저장. 서로 다른 기기/브라우저는 중복될 수 있으며 실제 사람 수나 참가 확정은 아님.
- 관리자 운영실 > 동행 모임의 모임별 실제 등록 기기 수. 공개 화면에는 수치 미표시.
- 마감/과거 모임에 신규 등록 불가, 전체 관심 취소는 모임이 사라져도 홈에서 가능.
- 이름/연락처/결제/실제 참가 명단 없음. 신규 유료 의존성 없음.

## 운영 DB 적용
1. 기존 프로젝트에서 v23 통합 SQL을 먼저 적용하고 검증합니다.
2. SQL Editor에서 [meetup-interest.sql](../supabase/meetup-interest.sql) 전체를 실행합니다. 기존 데이터를 삭제하지 않는 추가 설치입니다.
3. [v23 운영 안내](v23-owner-db-setup.md)에 따라 관리자 인증을 확인합니다.
4. 90일 경과 기록은 집계에서 제외됩니다. 운영자는 만료 기록 정리 SQL을 정기적으로 실행합니다(파일 마지막 주석). 정기 삭제를 설정하기 전까지 물리적 삭제는 자동이 아닙니다.

## 실기기 확인
- 운영자가 미래 날짜의 공개 모임을 하나 작성.
- 일반 홈에서 관심 버튼 → 동의 취소 시 저장 없음 → 동의 후 저장 성공 확인.
- 새로고침 후 관심 등록 유지, 같은 기기 반복 등록은 최대 한 건.
- 운영실 새로고침 후 기기 집계 변화 확인, 일반 화면에 집계 수치나 집결 장소가 노출되지 않음.
- 같은 기기에서 관심 취소 → 운영실 수 감소.
- 마감 후 신규 등록 불가, 홈의 전체 관심 취소는 가능.
- 다른 비관리자 계정/anon은 관리자 집계를 호출할 수 없어야 함.
- SQL 미설치 또는 통신 실패 시 성공 메시지/가짜 0 표시 금지.
- 실제 참가 신청·결제는 아직 지원하지 않음. 토큰 재생성에 따른 인위적 등록 가능성이 있어 집계는 참고용 수요로만 활용. 본격 공개 전 남용 방지 및 정기 삭제 운영 검토.
