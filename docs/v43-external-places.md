# v43 외부 장소 등록

관리자 코스 만들기 → 검색에 없는 장소 직접 추가 → 네이버/구글 지도 검색 → 공유 링크 복사 → 장소명·실제 주소·유형 입력 → 일치 확인 → 장소 등록 후 코스에 추가 → 코스 저장. 지역은 코스에 선택한 지역으로 저장합니다. 기존 카탈로그와 외부 장소를 최대 5곳까지 조합할 수 있습니다. 등록 장소는 관리자 검색에서 재사용 가능합니다. 외부 장소 등록은 코스 공개와 별개이며, 게시한 코스에 포함된 장소만 고객 조회 RPC에 표시됩니다. 지도 링크는 허용된 HTTPS 호스트만 허용합니다. 외부 사진·리뷰·평점 자동 수집 및 API 검색 결과 자동 가져오기는 포함하지 않습니다. 외부 장소가 첫 번째인 코스의 버튼은 활동별 일정 소식 수신 설정으로 이동하며 코스 단위 관심 신청을 뜻하지 않습니다. 일반 추천 엔진 및 기존 관광공사 카탈로그에는 추가하지 않습니다. 전국 코스 지역 지원은 운영 코스 전용입니다. 서버에는 external-places-v43.sql을 v42 이후 적용합니다. 실제 테스트용 레코드는 롤백합니다.
